# Mekiki Framework

The Mekiki Framework is a research program by **Kengo Tomita** on what can and cannot be delegated in AI-assisted knowledge work. Papers T1–T4 decompose the boundary of legitimate AI delegation; T5 asks the concluding converse question — why an agent may rationally decline delegation even when delegation is technically possible.
